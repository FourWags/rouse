# WagRise 0.1.51 — Clearer appearance choices Preview

The Original icon designs and Original color themes now have separate expandable menus. Each closed menu shows the current choice; opening it reveals the existing full card grid. Both menus can stay open together. A new **Clear appearance choices** action returns to the basic WagRise colors and icon, hides dog artwork, and removes selection marks until you choose again. Your saved personal themes remain available.

The dog picker remains first. Its 28 breed and mix portraits are still the actual home-screen icon choices, while coat colors set the app palette and alarm artwork. One portrait is bundled per breed; coat choices do not recolor that portrait. The Android package, signing certificate, and stable APK filename remain the same for in-place updates and Obtainium.

This is a personal Preview, not commercial v1 qualification.
